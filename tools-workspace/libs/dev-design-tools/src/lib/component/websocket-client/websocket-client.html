How to use
  • Enter a WebSocket URL (ws:// or wss://) and tap Connect.
  • Type a message in the compose area and tap Send or use the toolbar.
  • Received and sent messages appear in the log with timestamps.
  • Tap the copy icon on any message to copy its content.
