How to use GPX Viewer
  • Supported uploads: .gpx tracks, routes, and waypoints (GPX 1.0 / 1.1).
  • Invalid files are rejected early (empty, wrong type, oversized, bad coordinates, unusable XML).
  • Scroll to zoom, drag to pan, or use Fit / Zoom (+ − F 0). Toggle units with U.
  • Hover the elevation profile to inspect height; click to zoom the map. Selecting a track updates the profile.
  • Export GPX, CSV, or summary JSON — all processed in your browser. Map tiles load from OpenStreetMap.
