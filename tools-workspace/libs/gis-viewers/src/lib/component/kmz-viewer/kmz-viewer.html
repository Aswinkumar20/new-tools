How to use KMZ Viewer
  • Supported uploads: .kmz (zipped KML). The viewer prefers doc.kml when several KML files are present.
  • Scroll to zoom, drag to pan, or use Fit / Zoom controls (+ − F 0).
  • Filter features by geometry type, then click to focus and open attributes.
  • Export KMZ, KML, GeoJSON, CSV, or summary JSON — all processed in your browser. Map tiles load from OpenStreetMap.
