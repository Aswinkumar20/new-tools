How to use Drone Flight Path Viewer
  • Upload .gpx, CSV telemetry (lat/lon/alt/agl/battery/gimbal/photo), or LineString .geojson.
  • The map colors each segment by altitude (AGL preferred when present).
  • Takeoff/landing markers and photo waypoints appear when data includes them.
  • Export original, path GeoJSON, telemetry CSV, or summary JSON — all in your browser.
