  • Supported uploads: .tif, .tiff, .geotiff elevation grids (max 40 MB).

  • Optional relief tilt is a subtle CSS perspective — not a 3D engine.
  • Export GeoTIFF, summary, PNG, or contour GeoJSON when contours are enabled.
