How to use GeoPackage Viewer
  • Supported uploads: .gpkg (OGC GeoPackage / SQLite) with a gpkg_contents table.
  • Select a feature layer, filter by geometry type, and click a feature to focus and inspect attributes.
  • Scroll to zoom, drag to pan, or use Fit / Zoom controls (+ − F 0).
  • Export GeoJSON, CSV, summary JSON, or the original .gpkg — all processed in your browser. Tile layers are listed but not rendered in v1. Map tiles load from OpenStreetMap.
