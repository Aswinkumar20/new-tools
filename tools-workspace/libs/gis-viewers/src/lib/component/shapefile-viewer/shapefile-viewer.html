How to use Shapefile Viewer
  • Supported uploads: a .zip shapefile archive, or multi-select .shp + .dbf + .shx (optional .prj, .cpg).
  • Scroll to zoom, drag to pan, or use Fit / Zoom controls (+ − F 0).
  • Filter features by geometry type, then click to focus and open attributes.
  • Export GeoJSON, CSV, or summary JSON — all processed in your browser. Map tiles load from OpenStreetMap.
