How to use MBTiles Viewer
  • Supported uploads: .mbtiles SQLite packages with metadata and tiles tables (max 50 MB).
  • Raster formats (png/jpg/webp) render as map tiles. Vector (pbf/mvt) packages show a warning.
  • Scroll to zoom, drag to pan, or use Fit / Zoom controls (+ − F 0).
  • Export the original package, metadata JSON, or a summary — all processed in your browser.
