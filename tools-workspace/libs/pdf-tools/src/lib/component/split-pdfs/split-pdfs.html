How to Use

Step-by-step guide to split your PDF documents

1

Upload PDF

Click the "Browse" button or drag and drop your PDF file into the upload area. Supported file size: up to 100MB.

2

Choose Split Method

Select one of three split methods:

  • By Range: Specify page ranges (e.g., "1-5, 10-15, 20"). Each range becomes a separate file.
  • Every N Pages: Split the PDF into files containing N pages each (e.g., every 5 pages creates files with 5 pages each).
  • Extract Pages: Extract specific pages or ranges. Each page/range becomes a separate file.
3

Configure Options

Choose your output options:

  • Download as ZIP: Combine all split files into a single ZIP archive for easy download.
  • Output filename prefix: Set a prefix for the output files (e.g., "split" creates "split-1.pdf", "split-2.pdf").
4

Review & Split

Preview your PDF and review the split results. The results list shows how many files will be created and which pages each file contains. Click "Split & Download" to process and download your files.

💡 Tips & Tricks

  • Use the preview to verify which pages you want to split before processing.
  • Page ranges are inclusive (1-5 includes pages 1, 2, 3, 4, and 5).
  • You can mix single pages and ranges: "1, 3-5, 10" creates 3 files.
  • For large PDFs, splitting every N pages is faster than extracting specific pages.
  • Downloading as ZIP is convenient when creating many split files.
