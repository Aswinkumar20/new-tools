Options

Hashing runs locally via the Web Crypto API.

MD5 and SHA-1 are not available in this browser demo.

How to use
  • Enter text in the input editor and choose an algorithm in the sidebar.
  • Click Generate to compute the hash using Web Crypto.
  • Copy hex or base64 output using the per-section copy icons.
  • Toggle uppercase hex for checksums that require capital letters.
