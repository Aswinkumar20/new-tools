How to use
  • Paste sensitive text and set a password plus TTL in the sidebar.
  • Click Secure copy to copy to clipboard and encrypt in memory.
  • Content auto-clears when the timer expires.
  • Use Clear store to wipe the encrypted buffer immediately.
