Encryption uses AES-GCM with PBKDF2 — all local.

Notes live in memory only — refreshing clears them.

How to use
  • Write a note and set a password in the sidebar.
  • Click Encrypt to store ciphertext in memory and clear the editor.
  • Click Decrypt with the same password to restore the note.
  • Copy the encrypted blob to back it up externally if needed.
