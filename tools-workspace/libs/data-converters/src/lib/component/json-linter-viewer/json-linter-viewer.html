How to use

  1. Paste JSON or upload a file using the drag-and-drop zone.
  2. Toggle clean-up options to strip comments, trailing commas, or sort keys.
  3. Validate to view diagnostics and the formatted preview.
  4. Copy or download the cleaned output for your projects.

Switch preview modes to compare formatted versus minified payloads instantly.

Tips for accurate linting

  • Enable “Strip comments” before linting JSON that contains // or /* */ comments.
  • Sorting keys helps produce consistent diffs for configuration files.
  • Minified mode is great for network payloads; formatted mode is better for code reviews.
  • Use the diagnostics list to jump to problematic lines quickly.

Format insights

  • Set indentation to match your API style guide before exporting.
  • Remove trailing commas when preparing payloads for strict validators.
  • Leverage history to revisit previous linting runs without reuploading files.

Next steps
