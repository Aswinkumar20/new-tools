Tips for clean conversions

  • Enable smart typography to automatically polish quotes and ellipses.
  • Match team preferences by selecting Setext or ATX heading styles.
  • Choose the right code fence to keep documentation consistent.
  • Disable link preservation when you only need anchor text in Markdown.

Format insights

  • Escape raw HTML when converting Markdown to protect against embedded scripts.
  • Collapse whitespace when creating Markdown from CMS-generated HTML.
  • Use the history log to revisit earlier conversions without reuploading files.

Next steps
