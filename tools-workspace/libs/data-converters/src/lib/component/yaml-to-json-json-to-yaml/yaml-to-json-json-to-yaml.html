Best practices

  • Stick to spaces for YAML indentation—mixed tabs can break parsing.
  • Use quotes when keys include colons, spaces, or special characters.
  • Sort keys when committing YAML to keep diffs clean and predictable.
  • Validate by converting back to confirm semantic equivalence.

Format insights

  • Match indentation to your infrastructure repositories to avoid merge noise.
  • Pretty print JSON for human-friendly reviews before sharing.
  • Use consistent indentation (2 or 4 spaces) for better readability.
