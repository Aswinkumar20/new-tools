How to use

  1. Upload an Excel workbook (supports .xlsx, .xls, .csv, .ods, and others).
  2. Select a worksheet, preview the data, and adjust header detection.
  3. Optional: rename columns, change data types, or filter the columns to export.
  4. Convert and copy/download the JSON or CSV output for your applications.

Use sample data to try options before processing production spreadsheets.

Tips for clean exports

  • Use the first row as headers for consistent JSON keys.
  • Toggle date conversion to standardise timestamp formats.
  • Minimise output by selecting only the columns you need.
  • Sort keys when you require deterministic JSON for configuration files.

Format insights

  • Trim whitespace to keep payloads light and avoid mismatched keys.
  • Drop empty columns to prevent sparse objects in downstream pipelines.
  • Convert numbers and dates to keep analytics-ready data types.

Next steps

  • Archive the exported JSON as part of your ETL workflow.
  • Share the download with teammates responsible for API integration.
  • Use the JSON formatter to prettify data before checking it into source control.
