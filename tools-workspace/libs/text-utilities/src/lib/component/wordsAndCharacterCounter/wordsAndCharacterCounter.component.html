How to use
  • Type, paste, Upload, or drag & drop a text file — stats update instantly.
  • Click a word in the frequency table or cloud to highlight it in the editor.
  • Toggle Hide stop words for cleaner keyword density analysis.
  • Use Phrases for 2–3 word n-grams · Breakdown for character mix.
  • Export word frequency as CSV, or full report as PDF / TXT.
  • Ctrl+Z / Cmd+Z undo · Ctrl+Y redo.
