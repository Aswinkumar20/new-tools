Best practices

Keep URLs readable and consistent across marketing, docs, and product sites.

  • Use hyphens for SEO-friendly slugs; underscores are treated as characters.
  • Strip numbers when release versions belong elsewhere (e.g., metadata fields).
  • Preview final URLs with stakeholders before pushing to production.
