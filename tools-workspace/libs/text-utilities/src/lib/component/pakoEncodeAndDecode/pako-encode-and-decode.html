How to use
  • Choose Compress or Decompress, then pick deflate, raw, or gzip.
  • Select Base64 or Hex for binary output when compressing.
  • Use the same settings when decompressing data you compressed here.
  • Ctrl+Z / Cmd+Z undo · Ctrl+Y redo in the input editor.
