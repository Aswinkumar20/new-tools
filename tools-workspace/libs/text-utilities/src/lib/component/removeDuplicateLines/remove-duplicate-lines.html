How to use
  • Choose Words, Lines, or Both for the type of deduplication.
  • Paste lists, logs, or prose — duplicates highlight in source and sidebar.
  • Use Options for case sensitivity, punctuation, CSV first column, and more.
  • Selection previews cleanup on highlighted text only. Apply commits output to source.
  • Export via Copy, JSON, CSV, or TXT. No data is saved between sessions.
