Merge strategy

Conflict markers keep context intact while you resolve differences manually.

  • Rename labels to match your branches, e.g. feature/cart and main.
  • Disable markers to concatenate files when no conflicts are expected.
  • Copy the preview into your editor to resolve conflicts inline.

How to use

Merge code branches and resolve conflicts with our visual merge helper.

  1. Enter base content

    Paste your base branch or original content in the left panel.

  2. Add incoming changes

    Enter the incoming branch or modified content in the right panel.

  3. Configure labels

    Optionally rename branch labels to match your workflow (e.g., "main" and "feature").

  4. Toggle conflict markers

    Enable or disable conflict markers based on your merge strategy.

  5. Copy merged result

    Review the preview and copy the merged output to your editor for final resolution.
