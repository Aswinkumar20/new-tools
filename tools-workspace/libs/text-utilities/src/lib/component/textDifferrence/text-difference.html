How to use

Align your review workflow with rapid, readable diffs for docs, code, or configuration.

  • Paste or type directly in the panels to update the diff in real time.
  • Switch languages to enable syntax-aware highlighting for more clarity.
  • Toggle themes to match your editor preferences when sharing screenshots.

Keyboard shortcuts

Monaco brings familiar editor productivity to the diff surface.

⌘ / Ctrl + S

⌘ / Ctrl + F

Open in-editor search inside each pane to jump to changes.

Alt + F12

Peek definitions when using code languages such as TS or JS.

About this tool

Everything you need to know about our visual diff viewer.

The Text Difference Viewer is a powerful side-by-side comparison tool powered by Monaco Editor. It highlights differences between two versions of text, code, or documents in real-time, making it easy to spot changes, review edits, and understand modifications.

Monaco editor
