How to use
  • Type, paste, Upload, or drag & drop text in Source — output updates instantly.
  • Search or browse 40+ presets across Standard, Programming, and Fun tabs. Star favorites and use keys 1–5.
  • Line-by-line converts each row independently. Selection converts highlighted text only.
  • Swap or → In moves output back to source. Export via Copy, JSON, CSV, TXT, or Share link.
  • Options panel: locale, Unicode normalize, code escape, custom regex rules, title exceptions.
  • Ctrl+Z / Cmd+Z undo · Ctrl+Y / Cmd+Shift+Z redo.
