How it works

Depending on the mode, we either reverse characters or strip non-alphanumerics before comparison.

  • Palindrome mode ignores case, punctuation, and whitespace to focus purely on characters.
  • Reversal mode keeps formatting intact, ideal for generating mirrored text.
  • Use the copy buttons to move results into notes, QA docs, or developer handoffs.
