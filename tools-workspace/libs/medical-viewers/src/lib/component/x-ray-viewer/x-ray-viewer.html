How to use X-Ray Viewer
  • Upload CR/DX/XR/RF radiograph .dcm / .dicom / .ima files. Other modalities warn softly but still load.
  • Multiple files appear as a simple list — select a file or use arrow keys to switch between them.
  • Radiograph presets (Chest, Bone, Abdomen, Soft tissue) plus custom W/L. Invert, rotate 90°, zoom, and pan when zoomed past fit.
  • Export original, metadata JSON, summary JSON, or a PNG snapshot. Education/research only — not for diagnostic use.
