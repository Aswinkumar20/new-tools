How to use DICOM Viewer
  • Upload uncompressed .dcm / .dicom / .ima. Compressed transfer syntaxes soft-fail with a clear warning.
  • Adjust window/level with sliders or Soft Tissue / Bone / Lung / Brain presets. Invert and zoom as needed.
  • Multi-file series sort by InstanceNumber; multi-frame files use the frame slider. Arrow keys or mouse wheel change slice/frame. Ctrl+wheel zooms.
  • Click the image to probe raw + HU (SUV for PET). Filter metadata tags. Export original, metadata JSON, summary JSON, or a PNG snapshot.
