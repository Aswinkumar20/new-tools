About Archive Viewer

Everything you need to manage and inspect archive contents directly in your browser.

What is Archive Viewer?

Archive Viewer lets you explore archive contents, preview files, and extract what you need without leaving the browser. Full ZIP support is available today, with additional formats arriving soon.

Key capabilities

  • Hierarchical file tree with quick expand/collapse
  • Instant previews for text and image files
  • Password-protected archive handling
  • Search across entire archive content
  • Download individual files or extract everything
