What is Audio Player?

Audio Player is a comprehensive audio playback tool that supports multiple formats and provides advanced features like playlists, visualizations, and playback controls.

Features

  • Support for multiple audio formats (MP3, WAV, OGG, FLAC, AAC, M4A, etc.)
  • Playlist management with drag & drop
  • Playback controls (play, pause, stop, next, previous)
  • Progress bar with seek functionality
  • Volume control and mute
  • Playback speed control (0.5x - 2x)
  • Repeat modes (none, all, one)
  • Shuffle mode
  • Audio visualization with waveform
  • Time display (current/total)
  • Download functionality
