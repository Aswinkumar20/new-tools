About Text File Viewer

Everything you need to explore and analyze text-heavy content.

What is Text File Viewer?

A robust, browser-based inspector with syntax highlighting, line numbers, and fast search—ideal for reviewing logs, configuration files, code snippets, and structured data.

How to use

  1. Upload files: Drag & drop or select supported text formats.
  2. Search quickly: Use Ctrl/⌘ + F and navigate matches with Ctrl + G.
  3. Adjust readability: Toggle wrapping, show line numbers, and tune zoom.
  4. Go fullscreen: Present detailed logs or code excerpts distraction-free.
  5. Export results: Copy, download, or print content directly.

Key features

  • Syntax highlighting: JSON, XML, YAML, markup, styles, scripts, and more.
  • Advanced search: Case-sensitive mode with keyboard navigation.
  • Layout controls: Line numbers, wrapping, zoom from 50% to 200%.
  • Multi-file support: Review and switch between multiple files instantly.
  • Privacy-first: Files never leave your browser session.

Supported formats

Text formats: TXT, LOG, MD, RTF

Structured data: JSON, XML, YAML/YML, CSV

Code snippets: HTML, CSS, JS, TS, PY, SH, BAT, PS1

Size limit: 10MB per file

Browser compatibility: Modern Chrome, Edge, Firefox, Safari

Keyboard shortcuts

Ctrl + F Search
Ctrl + G Find next
Shift + Ctrl + G Find previous
Esc Exit fullscreen
