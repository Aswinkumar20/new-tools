Pro tips

Level up your text file review workflow.

  • Use Ctrl + F (or ⌘ + F) to jump into search immediately.
  • Toggle line numbers and wrapping to match code or prose review.
  • Copy, download, or print files without leaving the browser.
  • Navigate search results with Ctrl + G for next and Shift + Ctrl + G for previous.
  • Press Escape to exit fullscreen mode at any time.
