What is Log Viewer?

Log Viewer is a high-performance tool for viewing, searching, and analyzing log files. It automatically detects log levels, extracts timestamps, and provides powerful filtering and analytics capabilities.

Features

  • Automatic log level detection (DEBUG, INFO, WARN, ERROR, FATAL)
  • Real-time search with regex support
  • Filter by log level and date range
  • Color-coded log entries
  • Virtual scrolling for large files
  • Analytics and statistics
  • Multi-line log entry support (stack traces)
  • Copy to clipboard
  • Live mode with auto-scroll
