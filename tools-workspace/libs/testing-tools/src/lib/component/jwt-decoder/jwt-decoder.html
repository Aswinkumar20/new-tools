Options

Decoding runs locally — tokens never leave your browser.

This tool does not verify signatures or validate expiry.

How to use
  • Paste a JWT in the token editor — decoding runs automatically as you type.
  • Review Header, Payload, and Signature in the output panel.
  • Use copy icons to grab the raw token or decoded JSON.
  • Toggle pretty print to switch between compact and indented JSON.
