Results vary with caching, server load, and network conditions.

How to use
  • Enter a downloadable URL that allows cross-origin requests.
  • Set expected file size as a fallback if the response size is unknown.
  • Run multiple times (up to 5) to compare average speed.
  • Copy results to share or log measurements.
