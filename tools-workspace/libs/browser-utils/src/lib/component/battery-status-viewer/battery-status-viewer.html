How to use
  • Open on a supported device to see live battery level and charging state.
  • Use Refresh to re-read the battery manager, or Pause / Resume to control live events.
  • Copy plain text or JSON for bug reports; download history from Options when needed.
  • History keeps the last {{ historyLimit }} meaningful status snapshots (not duplicate event noise).
