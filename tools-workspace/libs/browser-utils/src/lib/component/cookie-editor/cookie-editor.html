How to use
  • Fill in name and value, then click Create to set a cookie.
  • Click a cookie in the list to load it into the editor for changes.
  • Use copy icons to grab individual values or the full cookie list.
  • Set days to expire to 0 for a session cookie.
  • Follow suggestions when a value looks like JWT/Base64 or when you need Storage Viewer.
